# TraceReceiptMinimizerEnv v0

Local fixture environment for receipt evidence selection.

Question:

> Given a messy trace packet and one bounded claim, can an agent select the
> minimum sufficient evidence, emit the warranted verdict, and state the missing
> evidence or boundary without overclaiming?

This environment is intentionally small. It uses fixture packets generated by
the receipt compiler and scores answer JSON. It does not call models, external
APIs, live cloud services, Kubernetes clusters, or GPUs. It adds no runtime
dependencies.

## What v0 Tests

The first slice uses one CloudTrail Lambda invocation and three authorization
policy siblings:

- missing `authorization.revoked_at` -> `unknown`
- explicit `authorization.revoked_at: null` -> `supported`
- `authorization.revoked_at` before the action -> `contradicted`

The scorer rewards:

- warranted verdicts;
- declared evidence refs;
- required field paths inside those evidence refs;
- missing-evidence discipline;
- explicit boundary language;
- `do_not_claim` entries that block false support;
- smaller evidence sets when they are still sufficient.

The scorer hard-zeroes:

- `supported` when the expected verdict is `unknown` or `contradicted`;
- invalid verdict vocabulary;
- evidence refs not declared in `task.json`;
- selected field paths not visible in the task;
- omitted `do_not_claim`;
- invented revocation or policy evidence.

## Layout

```text
cases/<task_id>/
  task.json
  expected.json
  artifacts/
    incident_manifest.json
    raw/
    imported/
    receipts/receipt.json
    reports/
answers/
  gold/
  baselines/
```

Generated receipts are included as reference artifacts. They are not listed as
agent-selectable evidence in `task.json`.

The task claim is narrower than the compiler claim: the task asks whether the
grant was active and not revoked at action time. The compiled receipt uses the
existing `authorization_bound_action` claim and carries revocation through its
deterministic `revocation_before_action` pass.

## Run

From the repository root:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 environments/trace_receipt_minimizer_v0/test_score.py
PYTHONDONTWRITEBYTECODE=1 python3 environments/trace_receipt_minimizer_v0/score.py --cases environments/trace_receipt_minimizer_v0/cases --answers environments/trace_receipt_minimizer_v0/answers/gold --json
PYTHONDONTWRITEBYTECODE=1 python3 environments/trace_receipt_minimizer_v0/score.py --cases environments/trace_receipt_minimizer_v0/cases --answers environments/trace_receipt_minimizer_v0/answers/baselines/full_trace --json
PYTHONDONTWRITEBYTECODE=1 python3 environments/trace_receipt_minimizer_v0/score.py --cases environments/trace_receipt_minimizer_v0/cases --answers environments/trace_receipt_minimizer_v0/answers/baselines/event_only --json

```

## Boundary

This is not a general agent benchmark. It is a local deterministic check that
the receipt compiler can feed an environment whose scorer distinguishes
minimum sufficient evidence from plausible false support.
