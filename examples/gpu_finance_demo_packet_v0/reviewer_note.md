# Reviewer Note

This folder is a Day 2 wrapper packet. The receipt cards and JSON receipts are
generated by ARC from existing examples; they are not handwritten.

Run the commands in `commands.txt` from the repository root to regenerate the
two Day 2 receipt cards:

- `receipt_cards/capacity_supported.txt`
- `receipt_cards/mig_unknown.txt`

No customer proprietary data is included. The packet uses existing ARC fixtures
and labels evidence source types explicitly in `evidence_manifest.json`.

The MIG receipt is `unknown` because the evidence is ambiguous when MIG is
enabled without GI/CI records. ARC reports that in the verdict basis; it does
not list GI/CI records under `Evidence missing` in the card.
